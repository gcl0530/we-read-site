核心功能 CORE FEATURES

一条从「数据」到「认知」的本地流水线：自动采集 → 正文存档 → AI 批注 → 每周决策。全部运行在你自己的电脑上，不依赖任何云端服务。

01 · 采集

公众号数据采集

微信扫码登录后自动抓取关注号的文章列表与阅读数据。支持全量首采与增量更新，断点续爬，内置限速与风控保护，一次更新覆盖全部号。

扫码登录增量更新断点续爬防风控限速
02 · 存档

正文本地存档

把文章正文抓进本地 SQLite 库，防删除、防设限。配全文倒排索引，标题与正文一起搜，命中即看本地正文，关键词高亮——文章没了也丢不了。

防删文全文检索关键词高亮阅读进度条
03 · 批注

AI 分周批注引擎

按周给文章生成「速览四段式」与类型化批注：道法（原则）/ 陪伴（情绪样本）/ 术器（可复用工具）/ OPC（客观-判断-结论）。AI 起草、你审改，一键导出笔记式 Markdown。

分周速览四类标签人工可编辑导出 Markdown
04 · 决策

每周决策工作台

共振信号自动聚合「同周多个号都在说」的主题，标注新增/持续；结合爆款榜、批注认知与号动态，一个页面翻完本周发生了什么。支持周台账与周简报导出。

共振信号新增/持续标注周台账周简报导出
05 · 控制台

本地 Web 控制台

浏览器即开即用的九页签工作台：文章流按日分组、已读标记；批注按周浏览与编辑；任务页一键触发采集；深浅色主题可切换。数据全程本地，127.0.0.1 只绑本机。

九页签深浅色主题任务编排本机回环绑定
