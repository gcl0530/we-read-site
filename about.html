关于系统 ABOUT

WE_READ 是一套本地运行的公众号数据工作台：把关注的公众号变成可检索、可批注、可回溯的认知系统。它不是云服务，不是 SaaS——数据、代码、运行环境都在你自己的电脑上。

技术栈

PythonSQLite微信读书数据管道 本地 Web 控制台LLM 批注引擎倒排全文检索

采集端通过浏览器自动化完成微信扫码登录与文章抓取；数据统一落进本地 SQLite；批注由 LLM 生成「速览 + 类型化批注」后入库，支持人工审改。控制台是只绑本机回环的 Web 界面，浏览器即开即用。

隐私与安全

数据全程本地：微信登录态、浏览器会话、文章与批注数据都不出本机，无任何云端回传。控制台仅绑定 127.0.0.1，不对局域网或公网开放。正文存档仅用于个人学习与复盘。

为什么这么做

公众号文章是「读时觉得有收获、读完全忘光」的典型。与其靠印象，不如交给系统：采集帮你不错过，存档帮你防删文，批注帮你把每周内容压缩成可复用的认知单元，决策页帮你把零散信息拼成本周发生了什么。
